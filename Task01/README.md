# Task01 — исходные данные

## Файлы данных

| Файл | Формат | Описание |
|------|--------|----------|
| `movies.csv` | CSV: `movieId,title,genres` | Фильмы. Жанры разделены символом `\|` |
| `ratings.csv` | CSV: `userId,movieId,rating,timestamp` | Оценки пользователей (0.5–5.0) |
| `tags.csv` | CSV: `userId,movieId,tag,timestamp` | Теги пользователей к фильмам |
| `users.txt` | разделитель `\|`: id, имя, email, пол, дата регистрации, профессия | Пользователи |
| `genres.txt` | по строке на жанр | Список жанров |
| `occupation.txt` | по строке на профессию | Список профессий |

## Файлы решения

- `ratings_count.txt` — минимальный и максимальный `userId` из `ratings.csv` и количество оценок для каждого.
- `sqlite.txt` — версия установленного SQLite и доступные режимы вывода.
