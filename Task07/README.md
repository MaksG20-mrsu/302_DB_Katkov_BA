# Task07. Консольное и веб-приложение СТО

Программы показывают **фактически оказанные услуги** из базы автосервиса Task06.
Для каждой работы выводятся номер мастера, его фамилия и имя (в исходной базе
отчество не хранится), дата и время выполнения, название услуги и фактическая
стоимость. Сортировка: фамилия мастера, дата и время работы по возрастанию.

## Требования

- PHP 8.0 или новее с расширением `pdo_sqlite`.
- Для корректного вывода кириллицы в консоли нужна кодировка UTF-8, например Git Bash.
- `mbstring` используется, если установлен; для кириллицы и латиницы предусмотрен
  вариант вывода таблицы без этого расширения.
- Apache, Composer и сторонние библиотеки не требуются.

## Подготовка базы

Откройте терминал в каталоге `Task07` и выполните:

```bash
php init_db.php
```

Будет создана база `service_station.db`: четыре мастера и восемь выполненных
услуг. `db_init.sql` — копия SQL-скрипта решения Task06; она включена, чтобы
приложение можно было запустить отдельно от других веток репозитория.
Повторный запуск `init_db.php` сохраняет уже существующую базу.
Сгенерированный файл базы исключён из Git через `.gitignore`.

Для подключения к другой базе с той же структурой можно задать переменную
окружения `STO_DB_PATH` с путём к файлу SQLite.

## Консольная программа

```bash
php task7_cli.php
```

Сначала программа получает из БД список всех мастеров и показывает их номера
и имена. Введите номер из показанного списка для фильтрации либо нажмите Enter
для вывода всех работ. Нечисловой или отсутствующий в базе номер отклоняется,
после чего программа повторно запрашивает ввод.

Вывод оформлен таблицей из символов псевдографики. Если у выбранного мастера нет
выполненных работ, выводится сообщение об отсутствии данных.

## Веб-приложение

Из каталога `Task07` запустите встроенный сервер PHP:

```bash
php -S 127.0.0.1:8000
```

Откройте в браузере [http://127.0.0.1:8000/index.php](http://127.0.0.1:8000/index.php).
Выберите мастера из раскрывающегося списка и нажмите «Показать».
Пункт «Все мастера» и ссылка «Сбросить» снимают фильтр.
Остановка сервера — Ctrl+C в терминале.

`index.php` формирует HTML как шаблон: используются короткие теги вывода `<?= ?>`
и альтернативный синтаксис `if: ... endif;`, `foreach: ... endforeach;`.
Операторов `echo` в шаблоне нет. Текст из базы экранируется перед выводом в HTML.
Некорректный параметр фильтра обрабатывается с HTTP-кодом 400.

## Работа с данными

- Общие функции находятся в `database.php`.
- Подключение — PDO; выборки выполняются подготовленными запросами.
- Номера мастеров читаются из `employees`; перечень номеров в коде не задан.
- Фильтр передаётся параметром `:master_id`, привязанным как `PDO::PARAM_INT`.
- Отменённые и только запланированные услуги не попадают в список выполненных работ.
- Работы уволенных мастеров отображаются, как и в базе Task06.
- Стоимость берётся из факта выполнения работы, а не из текущего прайс-листа.
